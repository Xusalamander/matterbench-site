# MatterBench

OriginFab 的 MatterBench 官网与在线体验。纯静态页面。

MatterBench is OriginFab's AI-assisted desktop fabrication system. This repository holds its public website and browser demo.

## 页面

- `index.html` · 产品介绍、作品演示回放、报名入口
- `demo.html` · 在线体验:拼豆像素画、发光灯罩、会动的小人、立体搭建四关

## 本地预览

```bash
python -m http.server 5192
```

打开 http://localhost:5192 。

## 部署

Cloudflare Pages,连接本仓库,输出目录为根目录。
